# 构建与运行

## 1. 环境要求

| 组件 | 版本 | 说明 |
|---|---|---|
| JDK | 17 | 必须包含 `jlink`（AGP 8.x 需要），推荐 `openjdk-17-jdk` 完整包 |
| Gradle | 8.9 | 仓库已带 Wrapper，无需单独安装 |
| Android SDK Platform | 35 | `platforms;android-35` |
| Android Build-Tools | 35.0.0 | `build-tools;35.0.0` |
| Android Studio | Ladybug (2024.2) 或更新 | 可选，命令行也能构建 |

依赖版本集中在 `gradle/libs.versions.toml`：

```toml
agp = "8.7.2"
kotlin = "2.0.21"
composeBom = "2024.10.01"
lifecycle = "2.8.6"
activityCompose = "1.9.2"
datastore = "1.1.1"
```

## 2. 首次配置

### 2.1 SDK 路径

复制模板并改成你自己的路径：

```bash
cp local.properties.template local.properties
# 编辑 local.properties
# sdk.dir=/Users/you/Library/Android/sdk      (macOS)
# sdk.dir=C\:\\Android\\Sdk                    (Windows)
# sdk.dir=/home/you/Android/Sdk                (Linux)
```

### 2.2 环境变量

```bash
export JAVA_HOME=/path/to/jdk-17
export ANDROID_HOME=/path/to/Android/Sdk
```

Android Studio 打开工程时会自动读取 `local.properties`，无需设环境变量。

## 3. 构建

### 3.1 Debug APK

```bash
./gradlew :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

### 3.2 Release APK

先配置签名（`app/build.gradle.kts` 里已有注释掉的 `signingConfigs` 块）：

```kotlin
android {
    signingConfigs {
        create("release") {
            storeFile = file("your.jks")
            storePassword = "******"
            keyAlias = "key0"
            keyPassword = "******"
        }
    }
    buildTypes {
        release {
            signingConfig = signingConfigs.getByName("release")
            isMinifyEnabled = false   // 如需混淆改为 true 并配置 proguard
        }
    }
}
```

```bash
./gradlew :app:assembleRelease
```

### 3.3 单元测试

```bash
./gradlew :app:testDebugUnitTest
# 报告：app/build/reports/tests/testDebugUnitTest/index.html
```

当前 9 个用例全部覆盖 `NumberParser` 与 `Formatter`。

## 4. 安装到设备

```bash
# USB 连接 + 开启 USB 调试
adb install -r app/build/outputs/apk/debug/app-debug.apk

# 或直接
./gradlew :app:installDebug
```

## 5. 权限

| 权限 | 用途 | 获取方式 |
|---|---|---|
| `SYSTEM_ALERT_WINDOW` | 悬浮窗 | 首次启动悬浮窗时跳系统设置页授权 |
| `POST_NOTIFICATIONS` | 前台服务通知（Android 13+） | 运行时请求 |
| `QUERY_ALL_PACKAGES` | 枚举已安装应用 | 安装即授予 |
| `ACCESS_SUPERUSER` | Root 内存访问 | 由 su 管理器（Magisk 等）授予 |
| 存储权限 | 导入/导出列表与内存 | 运行时请求 |

没有悬浮窗权限时悬浮球不会出现；没有 Root 时引擎进入沙盒模拟模式，
界面全部功能仍可完整体验。

## 7. 特殊环境说明

### 7.1 aarch64 构建机

AGP 通过 `aapt2FromMavenOverride` 下载的 `aapt2` 是 x86-64 ELF，
在 ARM 服务器上无法直接执行。两种解决方式：

**方式 A（推荐，无副作用）**：使用 ARM 原生 build-tools

```bash
sdkmanager "build-tools;35.0.0"
# 若官方包无 arm64 版本，见方式 B
```

**方式 B**：用 qemu 包装（本项目在开发时采用）

```bash
sudo apt-get install -y qemu-user-static
# 准备一个 x86-64 rootfs（如 ubuntu-base-amd64）
cat > /path/to/aapt2-wrapper <<'EOF'
#!/bin/bash
exec /usr/bin/qemu-x86_64-static -L /path/to/amd64root \
     $ANDROID_HOME/build-tools/35.0.0/aapt2 "$@"
EOF
chmod +x /path/to/aapt2-wrapper
```

然后构建时传入（**不要写进 gradle.properties**，否则其他机器会失败）：

```bash
./gradlew :app:assembleDebug -Pandroid.aapt2FromMavenOverride=/path/to/aapt2-wrapper
```

`gradle.properties` 里已保留该行注释，方便需要时启用。

### 7.2 国内网络

如果依赖下载慢，可在 `settings.gradle.kts` 的两个 `repositories` 块最前面加入镜像：

```kotlin
maven { url = uri("https://maven.aliyun.com/repository/public/") }
maven { url = uri("https://maven.aliyun.com/repository/google/") }
```

## 8. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `jlink executable does not exist` | JDK 是 headless / 精简版 | 安装完整 `openjdk-17-jdk` |
| `AAPT2 aapt2 Daemon startup failed` | 架构不匹配 | 见 7.1 |
| `SDK location not found` | 缺 `local.properties` | 见 2.1 |
| 悬浮球不出现 | 未授予悬浮窗权限 | 设置 → 悬浮窗 → 授权 |
| 搜索一直是“模拟” | 无 Root 或 SELinux 拒绝 | 检查 `su` 是否可用；看设置页底部状态 |
| 中文乱码 | 文件编码 | 确认 IDE 与 `org.gradle.jvmargs` 的 `file.encoding=UTF-8` |
