> 版本：96.0 ｜ 交付日期：2026-10  
> 技术栈：Kotlin 2.0.21 + Jetpack Compose（BOM 2024.10.01）+ Material 3  
> 包名：`com.littlecodesauce.ggnext` ｜ compileSdk 35 ｜ targetSdk 35 ｜ minSdk 24

---

## 1. 项目定位

GGNext 是 **GG（GameGuardian）96 版** 界面与交互结构的现代化重制实现。

原项目是 2015 年前后的 Holo 风格 Java 代码（154 个类、反编译后约 4.2 万行），
本项目在其 UI 结构逆向分析的基础上，用 Compose 从零编写，**不复制、不引用安装包内任何文件**。

产出物是一套可直接在 Android Studio 打开、编译、二次开发的完整源代码工程。

## 2. 功能清单

### 2.1 内存检索引擎

| 能力 | 说明 |
|---|---|
| 精确搜索 | 单值匹配，支持 Byte/Word/Dword/Float/Double/Qword/Xor 七种类型 |
| 范围搜索 | `100~200` 闭区间；`100~~200` 反向区间 |
| 联合搜索 | `1;2;3` 相邻多值；`1;2;3:100` 带区域；`1;2::64` 有序模式 |
| 文本搜索 | `'abc'`（UTF-8）、`"abc"`（UTF-16LE）、`:abc`、`;abc` |
| 十六进制 | `1234h`、`h4142`、`0x1F4` |
| 异或搜索 | `100X7`（键值 1–4096） |
| 类型后缀 | `10D`、`10F`、`10W`、`10B`、`10Q`、`10E`、`10X`、`10A` |
| 改善（Refine） | 在已有结果集上二次过滤 |
| 内存读写 | 有 Root 时直读 `/proc/<pid>/mem`；无 Root 自动降级为沙盒模拟 |

### 2.2 数据存取

- 目标进程枚举：包名、pid、32/64 位、内存占用、应用图标（LRU 缓存 48 项）
- 内存区域：完整 15 类（Ch/Jh/Ca/Cd/Cb/Ps/A/J/S/As/V/O/B/Xa/Xs），带容量统计
- 地址条目：地址、值、类型、区域、冻结状态、指针链长度
- 已保存列表：命名、冻结开关、单条删除

### 2.3 界面

- 主页（配置入口）+ 工作面板（修改器主体）双形态
- 面板结构：导航栏 → 工具栏 → 进程栏 → 内容 → 区域条 → 状态条
- 四个页签：设置 / 搜索列表 / 保存列表 / 内存
- 内置键盘：5×7 数字符号键盘，光标安全插入
- 弹窗体系：进程、搜索、区域、编辑、数值格式、偏移、移除、工具栏、转到、变速、历史、函数、日志、悬浮窗、帮助、关于、外观、长按菜单、类型选择、地址编辑、文件管理、导出、分配

### 2.4 外观

- 8 套主题色预设（玫瑰/青翠/天青/蔚蓝/紫罗兰/琥珀/赤红/中性）
- 深色模式三态（跟随系统 / 深色 / 浅色）
- Android 12+ 动态取色
- 字体缩放（0.70–1.30）、弹窗圆角（0–28dp）可调

### 2.5 悬浮窗

- 悬浮球可拖拽、点击呼出覆盖面板、不再跳转 App
- 前台服务通知

## 5. 当前版本限制

以下能力在源码中预留了接口，但尚未接入实际实现，需在真机 + Root 环境下继续完善：

| 项目 | 现状 | 补齐方式 |
|---|---|---|
| 冻结循环 | UI 与模型完成，未接定时写回 | 在 `Session` 里加 `CoroutineScope` 定时器遍历 `saved.filter { it.freeze }` |
| 有序联合匹配 | 语法解析完成 | `MemoryEngine.search` 增加分块有序比对 |
| ARM/Thumb 反汇编 | 格式化掩码位已预留 | 接入 Capstone JNI |
| Lua 脚本 | 未实现 | 可先用 LuaJ 在独立进程运行 |
| 悬浮窗无权限回退 | 目前只走 `TYPE_APPLICATION_OVERLAY` | 参考原版 `Tools.fixViewParams`，无权限时降级 `type=2` + window token |
| 设置项持久化覆盖度 | 主要项已存 DataStore | `SettingsSpecs` 中新增项需同步补读写 |
