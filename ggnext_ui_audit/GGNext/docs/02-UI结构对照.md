## 5. 数据结构对照

原版使用位掩码 `flags` 表示类型、符号与模式，本项目完整保留：

```kotlin
object ValueType {
    const val BYTE = 1;  const val WORD = 2;   const val DWORD = 4
    const val XOR = 8;   const val FLOAT = 16; const val QWORD = 32
    const val DOUBLE = 64; const val AUTO = 127

    // 符号位
    const val SIGN_EQUAL = 0x20000000
    const val SIGN_NOT_EQUAL = 0x10000000
    const val SIGN_GREATER_EQ = 0x04000000
    const val SIGN_LESS_EQ = 0x08000000
}
```

地址条目对应原版 `AddressItem` / `SavedItem`：

```kotlin
data class MemoryItem(
    val address: Long,
    var value: Long,
    var flags: Int,          // 类型位掩码
    var name: String,        // 已保存列表的名称
    var checked: Boolean,
    var region: String,      // Jh / Ca / Xa ...
    var freeze: Boolean,
    var pointer: Int         // 指针链长度
)
```

## 6. 输入语法对照

原版 `ParserNumbers` + `SearchButtonListener` 支持的语法，本项目全部实现于
`engine/NumberParser.kt`，并有 9 个单元测试覆盖：

| 语法 | 示例 | 解析结果 |
|---|---|---|
| 十进制 | `1234` | NUMBER, 1234 |
| 十六进制后缀 | `1F4h` | NUMBER, 0x1F4 |
| 十六进制前缀 | `h1F4` / `0x1F4` | NUMBER, 0x1F4 |
| 浮点 | `12.5`（类型选 Float） | FLOAT, 原始位模式 |
| 范围 | `10~20` | RANGE, sign=EQUAL |
| 反向范围 | `10~~20` | RANGE, sign=NOT_EQUAL |
| 联合 | `1;2;3` | GROUP, area=512 |
| 有序联合 | `1;2::64` | GROUP, ordered=true, area=64 |
| 文本 UTF-8 | `'abc` | TEXT, 3 字节 |
| 文本 UTF-16LE | `"abc` | TEXT, 6 字节 |
| 异或 | `100X7` | NUMBER, xorKey=7 |
