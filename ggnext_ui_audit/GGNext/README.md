# GGNext (纯 UI 源码工程版)

基于 GameGuardian (GG 96.0) 现代化重制的 Android 修改器纯 UI 源码工程。
采用 **Kotlin 2.0 + Jetpack Compose + Material 3** 构建，**无 C++ / NDK 编译依赖**。

## 本版本核心特性
1. **纯粹的 Android Compose 架构**：移除所有 CMake / NDK / 原生共享库依赖，开箱即用，任意标准 Android Studio 环境可直接秒编译、秒调试。
2. **完整保留全部 UI 缺陷修复与体验升级**：
   - **悬浮球长按变速与深浅色模式跟随**：彻底解决变速后悬浮球图标在深色模式下的反色异常。
   - **数值修改大括号回显**：修改数值后严格对齐原版 GG，在修改后数值后以 `{新值}` 格式大括号清晰展示修改器数值。
   - **进程防误清空**：重新选择当前已选进程时，不再清空搜索列表与已选数据。
   - **横向扁平化展开**：搜索界面的数据类型与搜索条件选择采用与地址修改面板一致的横向网格展开，不再垂直堆叠遮挡视野。
   - **范围搜索闭区间修复**：修复形如 `999~999` 的范围搜索边界越界问题，精准匹配指定区间。
   - **弹窗防误触关闭**：点击功能面板内的非控件区域（空白处）不再误关弹窗，仅点击遮罩区域或关闭按钮才会收起。
   - **子功能入口防关闭**：在搜索界面与修改面板中点击历史记录或辅助按钮时，主面板稳定驻留，不会误关闭。
   - **工具栏拖动边缘自动跟随滚动**：长按移动工具栏按钮至最左或最右边缘时，栏目自动平滑滑动以展示隐藏区域；工具栏顺序调整面板同样支持边缘自动滚动。
   - **运行日志实时清屏**：在设置页中点击“清理日志”后，界面状态实时同步清空，无需重新进入。
   - **文件选择器精简过滤**：移除冗余的快捷路径文字，默认自动过滤以 `.` 开头的隐藏文件。
   - **脚本历史记录手势操作**：支持条目左滑呼出快捷操作栏（置顶/固定、编辑、删除）。
   - **动态壁纸取色开关**：采用标准开关控件替代复选框。
   - **右下角非阻断浮动提示**：搜索结果输出与开关提示统一定位至屏幕右下角浮动呈现，不再遮挡正中屏幕。
   - **工作模式自适应**：未获得 Root 权限时自动默认为免 Root 模式（展示青色共享 UID 提示）；获得授权时支持一键无缝切换。

## 构建与运行
在 Android Studio 中直接打开本项目，或使用命令行执行：
```bash
./gradlew :app:assembleDebug
```
生成 APK 路径：`app/build/outputs/apk/debug/app-debug.apk`。
